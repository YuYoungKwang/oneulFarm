# oneulFarm 10분 데모 시연 스크립트

## 1. 흐름 기준

이번 데모 흐름은 아래 기준으로 구성한다.

- 기준 1: 실제 사용자 동선을 먼저 보여준다.
- 기준 2: 서비스의 핵심 정체성인 `농산물 중심 레시피 재료 판매 E커머스`를 앞에 둔다.
- 기준 3: `시세 분석`은 메인 기능이 아니라 구매 설득을 돕는 보조 기능으로 뒤에 둔다.
- 기준 4: 발표 초반에는 사용자 경험, 후반에는 데이터 근거와 운영 구조를 설명한다.

즉, 데모 순서는 `메인 → 레시피 → 재료 구매 → 주문 → 대시보드 → 시세 분석 → 관리자/식단 AI` 기준으로 진행한다.

## 2. 데모 목표

- 청중: 면접관, 교수
- 목표: 서비스 주제, 사용자 흐름, 차별점, 운영 가능성을 10분 안에 자연스럽게 전달한다.
- 핵심 메시지: oneulFarm은 시세 기반으로 농산물을 추천하고, 그 농산물로 만들 수 있는 레시피를 노출해 재료 구매까지 연결하는 농산물 중심 E커머스다.
- 보조 메시지: 합리적인 가격 구매와 절약 정보는 핵심이 아니라 구매 결정을 돕는 부가 서비스다.

## 3. 서비스 한 줄 소개

- 시작 문장
  - "oneulFarm은 시세 기반으로 추천한 농산물로 만들 수 있는 레시피를 보여주고, 그 재료 구매까지 연결하는 농산물 중심 레시피 재료 판매 E커머스입니다."
- 이어서 덧붙일 문장
  - "즉, 단순 가격 비교 서비스가 아니라 농산물 추천과 레시피 소비 경험을 연결해서 구매를 유도하는 구조가 핵심입니다."

## 5. 발표 스크립트

### 5.1 오프닝

- 시작 멘트
  - "oneulFarm은 시세 기반으로 추천한 농산물로 만들 수 있는 레시피를 보여주고, 그 재료 구매까지 연결하는 농산물 중심 레시피 재료 판매 E커머스입니다."
- 바로 이어서 말할 문장
  - "그래서 저희는 가격 비교 자체보다, 사용자가 어떤 농산물을 어떻게 소비할지까지 연결하는 데 더 집중했습니다."

### 5.2 메인 화면

- 이동 화면: `#/`
- 보여줄 포인트
  - 메인 배너
  - 시즌 농산물
  - 추천 레시피
- 설명 멘트
  - "메인에서는 지금 주목할 농산물과 그 재료로 만들 수 있는 레시피를 함께 보여줍니다."
  - "사용자가 상품만 보는 것이 아니라 무엇을 해 먹을 수 있는지까지 바로 떠올릴 수 있게 설계했습니다."
  - "즉, 메인부터 농산물과 레시피를 연결해 구매 진입을 만들었습니다."

### 5.3 레시피 목록과 레시피 상세

- 이동 화면

  - `#/recipes/{대표레시피번호}`
- 보여줄 포인트

  - 레시피 상세
  - 추천 재료 상품
  - 재료 한 번에 장바구니 담기
- 설명 멘트
  - "이 프로젝트의 핵심은 레시피가 콘텐츠로 끝나는 것이 아니라 바로 재료 구매로 이어진다는 점입니다."
  - "사용자는 레시피를 보고 필요한 재료를 확인한 뒤, 연결된 농산물을 장바구니에 바로 담을 수 있습니다."
  - "즉, 레시피가 구매 전환의 출발점 역할을 하도록 설계했습니다."

### 5.4 상품 상세, 장바구니, 체크아웃

- 이동 화면
  - `#/products/{대표상품번호}`
  - `#/cart`
  - `#/checkout`
- 보여줄 포인트
  - 판매가
  - 관련 레시피
  - 장바구니 담기
  - 주문서 작성
- 설명 멘트
  - "레시피에서 유입된 사용자가 실제 구매까지 이어질 수 있도록 상품 상세와 장바구니 흐름을 연결했습니다."
  - "상품 상세에서도 관련 레시피를 다시 보여줘서 상품과 식사 맥락이 끊기지 않게 했습니다."
  - "사용자는 단순히 농산물을 고르는 것이 아니라, 요리와 식단 맥락 안에서 재료를 구매하게 됩니다."
- 결제 설명 원칙
  - 라이브 결제 승인은 시연 안정성이 떨어지면 생략한다.
  - 체크아웃 화면까지만 보여주고 주문 완료 결과는 준비된 데이터로 설명한다.

## 6. 강조 포인트

- 가장 먼저 말할 것: 농산물 중심 레시피 재료 판매 E커머스라는 점
- 가장 오래 보여줄 것: 메인 추천, 레시피 상세, 레시피 기반 구매 연결
- 보조로 보여줄 것: 시세 분석, 절약 대시보드
- 짧게 넘길 것: 회원가입, 로그인, 기본 CRUD
- 시간이 부족할 때 줄일 순서
  - 주문 상세 설명
  - 관리자 주문, 배송 상세 설명
  - 대시보드 설명 일부
- 시간이 남으면 추가할 내용
  - 식단 AI를 통한 개인화 재료 구매 유도 전략

## 8. 데모 운영 원칙

- 발표 중심은 가격이 아니라 농산물과 레시피의 연결이다.
- 레시피가 어떻게 구매로 이어지는지 반복해서 강조한다.
- 시세 데이터는 구매 설득을 보조하는 장치로 설명한다.
- 절약 대시보드는 구매 후 가치로 설명한다.
- 식단 AI는 현재 서비스 확장 방향 또는 개인화 전략으로 소개한다.
