# oneulFarm 데모 리허설 체크리스트

## 1. 흐름 기준

리허설도 아래 기준으로 맞춘다.

- 실제 사용자 동선을 먼저 보여준다.
- 농산물과 레시피 연결을 메인으로 설명한다.
- 시세 분석은 보조 설명으로 뒤에 둔다.
- 식단 AI는 확장 방향으로 소개한다.

## 2. 발표 직전 준비

- 브라우저 탭을 미리 열어둔다.
  - `#/`
  - `#/recipes`
  - `#/recipes/{대표레시피번호}`
  - `#/products/{대표상품번호}`
  - `#/cart`
  - `#/checkout`
  - `#/dashboard`
  - `#/price-analysis`
  - `#/admin/purchase`
  - `#/meal-plan`
- 계정은 로그인 상태로 맞춰둔다.
- 레시피와 연결된 대표 상품 1개와 대표 레시피 1개를 미리 정해둔다.

## 3. 데이터 점검

- 메인 화면에서 아래 항목이 보이는지 확인한다.
  - 시즌 농산물
  - 추천 레시피
  - 메인 배너
- 레시피 상세에서 아래 흐름이 자연스러운지 확인한다.
  - 재료 목록 노출
  - 연결 상품 노출
  - 장바구니 담기
- 상품 상세에서 관련 레시피가 보이는지 확인한다.
- 대시보드에서 아래 항목이 노출되는지 확인한다.
  - 누적 절약 금액
  - 이번 달 절약 금액
  - 월별 절약 흐름
  - 자주 구매한 상품
  - 최근 구매 상품
- 시세 분석 화면에서 차트가 보이는지 확인한다.
- 관리자 화면에서 아래 데이터가 채워져 있는지 확인한다.
  - 매입 배치
  - 소분 이력
  - 상품 목록
  - 주문 목록

## 4. 발표 중 운영 규칙

- 메인 주제는 `시세 분석 서비스`가 아니라 `농산물 중심 레시피 재료 판매 E커머스`라는 점을 유지한다.
- 레시피에서 상품, 장바구니, 주문으로 이어지는 흐름에 가장 많은 시간을 쓴다.
- 시세 분석은 "사용자 메인 동선"이 아니라 "구매 판단을 돕는 보조 기능"으로 설명한다.
- 대시보드는 구매 후 가치로 설명한다.
- 식단 AI는 현재 확장 방향 또는 개인화 전략으로 설명한다.
- 화면 전환이 길어지면 미리 열어둔 탭으로 바로 넘어간다.
- 결제 단계는 외부 연동이 불안하면 체크아웃 화면까지만 보여준다.

## 5. 시간 부족 시 축약 순서

- 1순위 축약: 주문 상세 설명
- 2순위 축약: 관리자 주문, 배송 상세 설명
- 3순위 축약: 대시보드 상세 설명
- 유지해야 할 핵심
  - 메인 추천
  - 레시피 상세
  - 재료 구매 연결
  - 시세 기반 보조 설명

## 6. 마무리 멘트 체크

- 반드시 마지막에 아래 내용을 포함한다.
  - 농산물 중심
  - 레시피 기반 구매 유도
  - 시세 데이터는 보조 기능
  - 식단 AI 확장 가능성

## 7. 추천 한 줄 정리

- "oneulFarm은 시세 기반으로 추천한 농산물과 레시피를 연결하고, 그 재료 구매까지 이어지게 만드는 농산물 중심 레시피 재료 판매 E커머스입니다."
