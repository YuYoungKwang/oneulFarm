# oneulFarm 발표 패키지

## 목적
- 최종 발표를 실제 구현 기준으로 준비하기 위한 문서 패키지다.
- 팀 발표 기준으로 작성했고, 한 명이 전체를 발표해도 그대로 사용할 수 있게 구성했다.
- 발표 순서는 `문제 정의 -> 서비스 소개 -> 사용자 시연 -> 관리자 시연 -> 기술 구조 -> 차별점/성과 -> 마무리`로 고정했다.

## 문서 구성
- `oneulFarm_presentation_script.md`
  - 12분 이상 발표용 실제 대본
- `oneulFarm_demo_runbook.md`
  - 화면 시연 순서, 고정 동선, 리허설 체크리스트
- `oneulFarm_slide_support.md`
  - 발표 슬라이드 구성, 핵심 아키텍처 슬라이드, 보강 포인트
- `oneulFarm_qa.md`
  - 예상 질문과 답변, 답변 시 주의할 표현

## 핵심 메시지
1. 저희 팀은 공공 시세 데이터를 실제 구매 의사결정에 연결했습니다.
2. 저희 서비스는 구매 후 절약 효과를 대시보드로 체감하게 했습니다.
3. 저희 팀은 관리자 매입과 소분 운영까지 이어지는 구조를 구현했습니다.

## 사용 순서
1. `oneulFarm_presentation_script.md`로 전체 발표 흐름을 맞춘다.
2. `oneulFarm_demo_runbook.md`로 시연 동선을 고정한다.
3. `oneulFarm_slide_support.md`를 기반으로 발표 자료를 보강한다.
4. `oneulFarm_qa.md`로 예상 질문을 리허설한다.

## 발표 전 주의
- 현재 저장소 기준으로 사용자 기능과 관리자 기능은 실제 API 연동 범위가 넓다.
- 다만 발표에서는 외부 결제나 외부 API 상태에 따라 실패할 수 있는 구간을 길게 시연하지 말고, 핵심 가치는 `시세 비교`, `절약 체감`, `운영 연결`에 집중한다.
- 관리자 화면은 `oneulFarmAdminMode` 상태가 있어야 바로 진입할 수 있으므로 발표 전에 브라우저 상태를 미리 맞춘다.
